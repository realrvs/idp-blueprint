# ADR-0002: Kargo vs Argo Rollouts для прогрессивной доставки

- **Статус:** Proposed
- **Дата:** YYYY-MM-DD
- **Авторы:** Platform Team
- **Контекст blueprint:** [docs/blueprint.md](../blueprint.md)

## Контекст и проблема
Нужна прогрессивная доставка (canary/blue-green) с автоматическим откатом по метрикам.
Вопрос: достаточно ли Argo Rollouts или нужен Kargo для оркестрации промоушена
между окружениями.

## Рассмотренные варианты
1. **Argo Rollouts + Analysis Templates** — canary/blue-green на базе метрик Prometheus.
2. **Argo Rollouts + Kargo** — цепочки промоушена между 3+ окружениями с approval-гейтами.

## Решение
<Начать с Argo Rollouts. Kargo — только при появлении 3+ окружений с approval-гейтами.>

## Последствия
### Положительные
- Минимум движущихся частей: Argo Rollouts + Analysis Templates закрывают 80% сценариев canary/blue-green.
- Нет дополнительной оркестрации: промоушен между окружениями — через merge-request в GitOps-репозиторий.

### Отрицательные
- При 3+ окружениях с approval-гейтами придётся писать самописную логику промоушена.
- Нет встроенного UI для продвижения артефактов между окружениями.
-

## Критерий пересмотра
- Появление 3+ окружений с разными правилами промоушена.
- Необходимость ручных approval-гейтов на каждом шаге.
