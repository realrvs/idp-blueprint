# Диаграммы

Mermaid-диаграммы живут inline в `docs/blueprint.md` (рендерятся GitHub/GitLab).
Эта папка — для экспортированных PNG/SVG (например, для презентаций CTO/CISO).

## Соглашение об именах
- `NN-краткое-название.png` — где `NN` — порядковый номер по blueprint.
- Пример: `01-five-layers.png`, `02-sdlc-flow.png`, `03-mcp-auth.png`.
