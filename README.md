# IDP Blueprint: AI-Augmented Platform Engineering

Репозиторий содержит blueprint целевой архитектуры Internal Developer Platform
с интеграцией AI/RAG и агентской цепочки.

## Структура

- `docs/blueprint.md` — основной документ (v0.1, Draft)
- `docs/adr/` — Architecture Decision Records (формат MADR)
- `docs/diagrams/` — экспортированные диаграммы (PNG/SVG)
- `docs/runbooks/` — операционные runbooks платформы
- `scripts/` — скрипты автоматизации (включая генератор структуры)
- `.github/` — шаблоны PR и Issue

## Как начать

1. Прочитайте `docs/blueprint.md`.
2. Ознакомьтесь с ADR в `docs/adr/`.
3. Для изменений создавайте PR с описанием и ссылкой на ADR (если решение архитектурное).

## Версионирование

- `v0.x` — Draft, обсуждается
- `v1.0` — утвержден архитектурным комитетом
